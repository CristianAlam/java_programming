9. Trace Tables

A trace table lets you run a program by hand, line by line, to see what it does and find bugs. It has one column per variable and one for the output. Every row is one step.

  1. Make a column for the line number, one per variable, and one for the output.
  2. Go through the code in the order it runs. For each line that changes something, add a row.
  3. Write each new value. Leave a cell empty if the variable doesn't exist yet.

Example:

1  int a = 5;
2  int b = 8;
3  int temp = a;
4  a = b;
5  b = temp;
6  System.out.println(a + " " + b);
