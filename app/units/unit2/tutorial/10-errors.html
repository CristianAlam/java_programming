KindWhen you find outExamples
Syntax (compile) errorBefore running. The program won't start, and you get the line number.Missing ;

Runtime errorWhile running. The program crashes with a red message (an exception).10 / 0 gives ArithmeticException: / by zero

Logic errorNever automatically! The program runs but the answer is wrong. Only testing finds it.a + b / 2 instead of (a + b) / 2

How to test
Before running, work out the expected answer by hand for a few inputs. Choose inputs that are easy to check, and some tricky ones: 0, negative numbers, odd numbers for division.
Division by zero with double
Only int division by zero crashes. 5.0 / 0 gives Infinity, which is still a logic error.
