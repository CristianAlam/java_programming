11. Objects + Variables

Now that you have variables, you can store the values an object gives back, and calculate with them. The Bucket class from Unit 1 still works the same way:

Bucket big = new Bucket(7);
Bucket small = new Bucket(3);
big.fill();
big.pourInto(small);

int left = big.getCurrentAmount();                      // 4: store the returned value
double percent = 100.0 * left / big.getCapacity();      // 57.14...: calculate with it
System.out.println("big is " + Math.round(percent) + "% full");   // big is 57% full
