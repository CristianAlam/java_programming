3. Arithmetic Expressions

An expression is anything that has a value: 7, x, x + 1, (a + b) / 2. Java calculates (evaluates) it to get one value.

OperatorMeaningExampleValue
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division7 / 23 (see below!)
%Remainder (modulo)7 % 21

Order of operations

Same as in math: first parentheses, then * / %, then + -. Operators at the same level go left to right.

2 + 3 * 4       // 14   (3*4 first)
(2 + 3) * 4     // 20
20 / 4 * 2      // 10   (left to right: 5 * 2)
10 - 4 - 3      // 3    (left to right: 6 - 3)
Classic bug: the average
(a + b) / 2 is the average. a + b / 2 is a + (b / 2), which is wrong. When in doubt, add parentheses.

Integer division: quotient and remainder

When both sides are int, / gives a whole-number answer and throws away the rest. % gives what's left over. Think of sharing sweets:

17 sweets, 5 kids
17 / 5 = 3 each
17 % 5 = 2 left over
135 minutes
135 / 60 = 2 hours
135 % 60 = 15 minutes
The digits of 472
472 % 10 = 2 (units)
472 / 10 % 10 = 7 (tens)
472 / 100 = 4 (hundreds)
Useful % patterns
n % 2 is 0 for even numbers and 1 for odd ones. n % 10 is the last digit. n / 10 removes the last digit.
