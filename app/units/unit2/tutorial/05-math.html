5. The Math Library

Java comes with a class called Math: a library of ready-made math actions written by other programmers. You call them with the pattern ClassName.methodName(values):

CallWhat it doesExampleValue
Math.abs(x)Absolute valueMath.abs(-7)7
Math.max(a, b)The larger of twoMath.max(3, 9)9
Math.min(a, b)The smaller of twoMath.min(3, 9)3
Math.pow(a, b)a to the power of bMath.pow(2, 10)1024.0 (double)
Math.sqrt(x)Square rootMath.sqrt(25)5.0 (double)
Math.round(x)Round to the nearest whole numberMath.round(2.5)3
Math.random()A random decimal from 0.0 up to (not including) 1.0Math.random()e.g. 0.7184...
Math.PIThe number pi (a value, not an action: no parentheses)Math.PI3.14159...
double hyp = Math.sqrt(Math.pow(3, 2) + Math.pow(4, 2));     // 5.0  (Pythagoras)
int biggest = Math.max(a, Math.max(b, c));                   // largest of three: calls inside calls
int grade = (int) Math.round(84.6);                          // 85
double twoPlaces = Math.round(3.14159 * 100) / 100.0;        // 3.14
Math.round needs a cast to fit in an int
For a double, Math.round returns a very large whole-number type (long). Write int r = (int) Math.round(x);

Random whole numbers

Math.random() gives a decimal from 0 up to 1. To get a whole number from 1 to 6 (a die):

int die = (int) (Math.random() * 6) + 1;
  1. Math.random() gives something from 0 up to 1, e.g. 0.73
  2. * 6 gives something from 0 up to 6, e.g. 4.38
  3. (int) cuts the decimals: 0, 1, 2, 3, 4 or 5, e.g. 4
  4. + 1 gives 1 to 6, e.g. 5
General formula
A random whole number from low to high: (int) (Math.random() * (high - low + 1)) + low
