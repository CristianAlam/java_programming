7. Input: Reading from the Keyboard

To let the user type values, we use a ready-made class called Scanner. For now, treat it as a black box: copy the pattern, and use it.

import java.util.Scanner;                    // first line of the file: "I'll use Scanner"

public class Greeting {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);     // create a Scanner object, once

        System.out.print("How old are you? ");   // always tell the user what to type
        int age = in.nextInt();                  // wait for a whole number

        System.out.print("Your height in meters? ");
        double height = in.nextDouble();         // wait for a decimal number

        System.out.println("In 10 years you will be " + (age + 10) + ".");
    }
}
CallReads
in.nextInt()A whole number, as an int
in.nextDouble()A decimal number, as a double
in.next()One word, as a String
You already know this pattern!
new Scanner(...) creates an object, just like new Bucket(5). And in.nextInt() calls a method on it, just like big.fill().

Input in this app

In this app you type the input before you press Run, in the INPUT box under the code, one value per line. When the program reads a value, it appears in the output, as if you had typed it:

How old are you? 16
Your height in meters? 1.72
In 10 years you will be 26.
Already done for you
In this app, import java.util.Scanner; is part of the fixed frame. You only write the line that creates the Scanner: Scanner in = new Scanner(System.in);
When input goes wrong
If the program expects a number but gets a word (like abc), it crashes with InputMismatchException. If it tries to read more values than you typed, it crashes with NoSuchElementException.
In IntelliJ
There you type the input while the program runs: click inside the Run window at the bottom, type the value, and press Enter.
