Below main, write these three methods:

circleArea(r)Returns the area of a circle: PI * r * r
circlePerimeter(r)Returns the perimeter of a circle: 2 * PI * r
printCircle(r)Returns nothing. Prints one line using the two methods above, with both values rounded to 2 decimal places:
Radius 2.5: area = 19.63, perimeter = 15.71

Choose the right return type and parameter type for each one. Then, in main, call printCircle for the radiuses 1, 2.5 and 10.
