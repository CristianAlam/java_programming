7. Working in IntelliJ

In this unit you can do everything inside this app. From Unit 2 on, you will write your programs in IntelliJ IDEA, a professional Java editor.

TaskHow
New classRight-click the src folder → New → Java Class
RunClick the green Run arrow next to main, or press Shift + F10
SaveIntelliJ saves automatically
Comment linesSelect lines and press Ctrl + /

Step through a program one command at a time

  1. Click in the left margin next to a line to set a breakpoint (a red dot).
  2. Click the Debug button (the bug icon) instead of Run.
  3. Press F8 (Step Over) to run one command at a time and watch the output change.
Why this matters
Stepping through code is the best way to understand what a program really does, and to find bugs.
