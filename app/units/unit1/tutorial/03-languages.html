3. Programming Languages

The processor only understands machine language: long sequences of 0s and 1s. Humans write in high-level languages (Java, Python, C, ...), which are much closer to English. These get translated into something the computer can run.

Java in brief

1995
Released by James Gosling at Sun Microsystems
Write once, run anywhere
Bytecode runs on the JVM on any system
Used everywhere
Android, banks, big web servers, and the Israeli Bagrut
Hello.java (code you write) → javac (compile) → Hello.class (bytecode) → java (run) → Output
In IntelliJ and in this app
Pressing Run does both steps for you: it compiles your code, then runs it.
