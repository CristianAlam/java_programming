4. What is a Program?

A program is an algorithm written in a programming language. Working with programs means:

ActionMeaning
ReadUnderstand what existing code does
WriteType the code
RunLet the computer execute it
TestCheck that the output is what you expected
FixFind and correct mistakes (bugs)

Two kinds of mistakes

Syntax (compile) errors
The code breaks Java's rules, like a missing ; or ". The program won't run at all, and you get an error message with the line number.
Logic errors
The program runs but does the wrong thing, like printing the wrong text. Only testing reveals these.
