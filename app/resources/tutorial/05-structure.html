5. The Basic Structure: Class + main

Every Java program in this course lives inside a class and starts running from the main method.

public class Hello {                              // the class: a "container" for the program
    public static void main(String[] args) {      // main: where the program starts
        System.out.println("Hello, world!");      // a command (statement)
    }
}
For now
Treat public class ... and public static void main(...) as a fixed frame you write every time. In this app the frame is already written for you; you type only what goes inside main.

Rules to remember

Name = fileHello goes in Hello.java
Top to bottomCommands run one after another
SemicolonsEvery command ends with ;
Braces in pairsEvery { needs a matching }
Case-sensitiveSystem is not the same as system

Printing

CommandWhat it does
System.out.println("text");Prints the text, then moves to a new line
System.out.print("text");Prints the text and stays on the same line
System.out.println();Prints an empty line

Special characters inside text

Some characters can't be typed directly inside "...". Write them with a backslash \ instead:

WritePrintsExample
\nA new line"Line one\nLine two"
\tA tab (a wide space)"Name:\tDana"
\"A quote mark ""She said \"Hi\""
\\A backslash \" /\\" prints /\
Watch out
A single \ on its own is an error. To print one backslash, always write two: \\.

Comments

A comment is a note for humans. Java ignores it completely when running the program.

// This whole line is a comment
System.out.println("Hi");   // a comment can also come after a command
// System.out.println("Bye");   this command is "commented out", so it won't run
Shortcut
Select one or more lines and press Ctrl + / to comment them out. Press it again to uncomment them (remove the //). This works in IntelliJ and in this app.
