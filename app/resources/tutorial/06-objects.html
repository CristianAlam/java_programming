6. Objects

An object is a "thing" in the program that has a state and can perform actions. A class is the blueprint (the "cookie cutter") that objects are made from.

Class Bucket
The blueprint for all buckets
Objects small, big
Real buckets made from that blueprint, each with its own water
Using vs. implementing
You don't need to know how a class works inside in order to use it. You only need its interface: the list of actions you may perform.

Creating an object: new

Bucket small = new Bucket(3);   // a new, empty 3-liter bucket named "small"
Bucket big   = new Bucket(5);   // a second, separate 5-liter bucket

Calling a method: the dot

big.fill();           // "big, fill yourself!"
big.pourInto(small);  // pour from big into small, as much as fits
small.display();      // show small's state

Pattern: objectName.methodName(arguments);

The Bucket interface (keep this in front of you!)

ActionWhat it does
new Bucket(capacity)Creates a new empty bucket that holds capacity liters
fill()Fills the bucket to the top
empty()Empties the bucket completely
pourInto(otherBucket)Pours into otherBucket until this one is empty or the other is full
getCapacity()Returns how many liters the bucket can hold
getCurrentAmount()Returns how many liters are in the bucket now
display()Prints the bucket, e.g. [###..] 3/5 liters

You can print a returned value directly: System.out.println(big.getCurrentAmount());
