1What is Computer Science?

Computer science is about solving problems with computation. It isn't really "about computers", any more than astronomy is about telescopes.

🗺️
NavigationFind the shortest route between two cities
🩺
MedicineSpot tumors in thousands of scan images
🧬
BiologyCompare DNA sequences billions of letters long
💳
FinanceDetect credit-card fraud in real time
♟️
GamesBuild a computer opponent that plays chess well

All of these need two things: a clear method for solving the problem (an algorithm) and a way to tell a computer to carry it out (a program).

2Algorithms (אלגוריתם)

An algorithm is a finite, precise, ordered list of steps that solves a task. A recipe is a good everyday example.

🎯
PreciseEvery step is clear, with no guessing
🔢
OrderedThe order of the steps matters
🏁
FiniteIt ends eventually

Example: making tea

  1. Fill the kettle with water.
  2. Turn on the kettle and wait until it boils.
  3. Put a tea bag in a cup.
  4. Pour the boiling water into the cup.
  5. Wait 3 minutes.
  6. Remove the tea bag.
Think about itWhat happens if you swap steps 3 and 6? What if step 2 just said "heat the water"? Computers are very literal: they do exactly what you say, not what you meant.

4What is a Program? (תכנית)

A program is an algorithm written in a programming language. Working with programs means:

ActionMeaning
📖 ReadUnderstand what existing code does
✍️ WriteType the code
▶️ RunLet the computer execute it
🧪 TestCheck that the output is what you expected
🔧 FixFind and correct mistakes (bugs)

Two kinds of mistakes

🟥
Syntax (compile) errorsThe code breaks Java's rules, like a missing ; or ". It won't run, and IntelliJ underlines it in red.
🐛
Logic errorsThe program runs but does the wrong thing. Only testing reveals these.

5The Basic Structure: Class + main

Every Java program in this course lives inside a class and starts running from the main method.

public class Hello {                              // the class: a "container" for the program
    public static void main(String[] args) {      // main: where the program starts
        System.out.println("Hello, world!");      // a command (statement)
    }
}
For nowTreat public class ... and public static void main(...) as a fixed frame you write every time. You'll learn what each word means later.

Printing

CommandWhat it does
System.out.println("text");Prints the text, then moves to a new line
System.out.print("text");Prints the text and stays on the same line
System.out.println();Prints an empty line

Special characters inside text

Some characters can't be typed directly inside "...". Write them with a backslash \ instead:

WritePrintsExample
\nA new line"Line one\nLine two"
\tA tab (a wide space)"Name:\tDana"
\"A quote mark ""She said \"Hi\""
\\A backslash \" /\\" prints /\
Watch outA single \ on its own is an error. To print one backslash, always write two: \\.

Comments

A comment is a note for humans. Java ignores it completely when running the program.

// This whole line is a comment
System.out.println("Hi");   // a comment can also come after a command
// System.out.println("Bye");   ← this command is "commented out", so it won't run
IntelliJ shortcutSelect one or more lines and press Ctrl+/ to comment them out. Press it again to uncomment them (remove the //).

6Objects (עצמים)

An object is a "thing" in the program that has a state and can perform actions. A class is the blueprint (the "cookie cutter") that objects are made from.

📐
Class BucketThe blueprint for all buckets
🪣
Objects small, bigReal buckets made from that blueprint, each with its own water
Using vs. implementingYou don't need to know how a class works inside in order to use it. You only need its interface: the list of actions you may perform.

Creating an object: new

Bucket small = new Bucket(3);   // a new, empty 3-liter bucket named "small"
Bucket big   = new Bucket(5);   // a second, separate 5-liter bucket

Calling a method: the dot .

big.fill();           // "big, fill yourself!"
big.pourInto(small);  // pour from big into small, as much as fits
small.display();      // show small's state

Pattern: objectName.methodName(arguments);

The Bucket interface (keep this in front of you!)

ActionWhat it does
new Bucket(capacity)Creates a new empty bucket that holds capacity liters
fill()Fills the bucket to the top
empty()Empties the bucket completely
pourInto(otherBucket)Pours into otherBucket until this one is empty or the other is full
getCapacity()Returns how many liters the bucket can hold
getCurrentAmount()Returns how many liters are in the bucket now
display()Prints the bucket, e.g. [###..] 3/5 liters

You can print a returned value directly: System.out.println(big.getCurrentAmount());
