1Variables (משתנים)

In Unit 1 every program printed the same thing each time. To work with data, a program needs to remember values. It does that with variables.

A variable is a named box in the computer's memory that holds one value.

Every variable has three things:

🏷️
A nameFixed when you create it. age
📐
A typeWhat kind of value it holds. Fixed. int
🔄
A valueWhat's inside right now. This one can change, hence "variable".

Creating a variable

int age;                     // declaration: create a box called age for whole numbers
age = 16;                    // assignment: put 16 into the box

double height = 1.72;        // declaration + initialization in one line (most common)
int a = 3, b = 4;            // several of the same type in one line

System.out.println(age);     // prints the VALUE: 16
System.out.println("age");   // prints the TEXT:  age

Memory is limitedUnlike numbers in math, numbers in a computer have a size limit, because each box has a fixed size in memory. Going past the limit gives strange results: 2147483647 + 1 is -2147483648! And 0.1 + 0.2 prints 0.30000000000000004, because double can't store every decimal exactly.

2Assignment (השמה)

The = sign in Java is not "equals" like in math. It's a command: "calculate the right side, then put the result in the box on the left."

int x = 5;
x = x + 1;   // right side: 5 + 1 = 6. Put 6 into x. (In math this would be nonsense!)
x = x * 2;   // x is now 12

Assignment copies, it doesn't move

int a = 7;
int b = a;   // b gets a COPY of 7. a still holds 7.
a = 100;     // changing a later does NOT change b
100
a
int
7

Not like the buckets!In Unit 1, pourInto moved water: one bucket lost what the other gained. Assignment is different: it's like photocopying a note. The original stays exactly as it was.

Classic task: swapping two variables

To swap the values of a and b, you need a third, temporary box. Otherwise one value is overwritten and lost:

int temp = a;   // save a's value
a = b;          // now a can be overwritten
b = temp;       // put the saved value into b

Watch this step by step in the trace table simulator (program "Swap").

Shortcuts you'll see a lot

ShortcutMeans
x += 5;x = x + 5; (also -=, *=, /=, %=)
x++;x = x + 1;
x--;x = x - 1;
Use before giving a value = errorint n; System.out.println(n); doesn't compile: "variable n might not have been initialized". A box must get a value before you read it.

3Arithmetic Expressions (ביטויים חשבוניים)

An expression is anything that has a value: 7, x, x + 1, (a + b) / 2. Java calculates (evaluates) it to get one value.

OperatorMeaningExampleValue
+Addition7 + 29
-Subtraction7 - 25
*Multiplication7 * 214
/Division7 / 23 ⚠️ (see below)
%Remainder (modulo)7 % 21

Order of operations

Same as in math: first parentheses, then * / %, then + -. Operators at the same level go left to right.

2 + 3 * 4     // 14   (3*4 first)
(2 + 3) * 4   // 20
20 / 4 * 2    // 10   (left to right: 5 * 2)
10 - 4 - 3    // 3    (left to right: 6 - 3)
Classic bug: the average(a + b) / 2 is the average. a + b / 2 is a + (b / 2), which is wrong. When in doubt, add parentheses.

Integer division: quotient and remainder

When both sides are int, / gives a whole-number answer and throws away the rest. % gives what's left over. Think of sharing sweets:

🍬
17 sweets, 5 kids17 / 5 = 3 each
17 % 5 = 2 left over
⏰
135 minutes135 / 60 = 2 hours
135 % 60 = 15 minutes
🔢
The digits of 472472 % 10 = 2 (units)
472 / 10 % 10 = 7 (tens)
472 / 100 = 4 (hundreds)
Useful % patternsn % 2 is 0 for even numbers and 1 for odd ones. n % 10 is the last digit. n / 10 removes the last digit.

4int vs double: Converting Types (המרה)

The type of the result depends on the types of the values:

ExpressionTypesResult
7 / 2int / int3 (int)
7.0 / 2double / int3.5 (double)
7 / 2.0int / double3.5 (double)
3 + 1.5int + double4.5 (double)

Rule: if at least one side is a double, Java first converts the int to a double automatically, and the result is a double.

Automatic conversion: int → double ✅

double d = 5;   // OK: 5 becomes 5.0. No information is lost.
int n = 5.7;    // ❌ ERROR: "possible lossy conversion from double to int"

Java refuses to squeeze a double into an int by itself, because the decimal part would be lost. If you really want that, you must say so with a cast.

Casting: converting on purpose

int n = (int) 5.7;                       // 5  (cuts off the decimals, does NOT round!)
int total = 17, count = 4;
double wrong = total / count;            // 4.0  ← int division happened first!
double right = (double) total / count;   // 4.25 ← total becomes 17.0 first
The most common bug of this unitdouble avg = total / count; looks right but gives a whole number, because total / count is calculated as int / int before it goes into the double box. Fix it with (double) total / count or total / (double) count or 1.0 * total / count.

Random whole numbers

Math.random() gives a decimal in [0, 1). To get a whole number from 1 to 6 (a die):

int die = (int) (Math.random() * 6) + 1;
  1. Math.random() → somewhere in [0, 1), e.g. 0.73
  2. * 6 → somewhere in [0, 6), e.g. 4.38
  3. (int) cuts the decimals → 0, 1, 2, 3, 4 or 5, e.g. 4
  4. + 1 → 1 to 6, e.g. 5
General formulaA random whole number from low to high: (int) (Math.random() * (high - low + 1)) + low

6Text and Output: String

Text in Java has the type String. For now you only need two things: storing text in a variable, and gluing pieces together with + (concatenation, שרשור).

String name = "Dana";
int age = 16;
System.out.println("Hi " + name + ", you are " + age + ".");   // Hi Dana, you are 16.

When one side of + is a String, the other side is turned into text and glued on.

Watch the order!

+ works left to right. Once the result is text, every following + glues text:

CodePrintsWhy
"Sum: " + 3 + 4Sum: 34"Sum: 3" then + 4 glues "4"
"Sum: " + (3 + 4)Sum: 7Parentheses first: 3 + 4 = 7
3 + 4 + " is the sum"7 is the sum3 + 4 = 7 first, then text
Rule of thumbPut any calculation inside a println in parentheses: "Total: " + (price * amount).

7Input: Reading from the Keyboard (קלט)

To let the user type values, we use a ready-made class called Scanner. For now, treat it as a black box: copy the pattern, and use it.

import java.util.Scanner;                        // ① first line of the file: "I'll use Scanner"

public class Greeting {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);     // ② create a Scanner object, once

        System.out.print("How old are you? ");   // ③ always tell the user what to type
        int age = in.nextInt();                  // ④ wait for a whole number

        System.out.print("Your height in meters? ");
        double height = in.nextDouble();         // ④ wait for a decimal number

        System.out.println("In 10 years you will be " + (age + 10) + ".");
    }
}
CallReads
in.nextInt()A whole number → int
in.nextDouble()A decimal number → double
in.next()One word → String
You already know this pattern!new Scanner(...) creates an object, just like new Bucket(5). And in.nextInt() calls a method on it, just like big.fill().
In IntelliJWhen the program waits for input, click inside the Run window at the bottom, type the value, and press Enter. If you type abc when a number is expected, the program crashes with InputMismatchException.

8Helper Methods (פעולות עזר)

You've already used methods that others wrote: Math.sqrt, big.fill(), in.nextInt(). Now you'll write your own. A method is a named piece of code that does one task. You write it once and call it whenever you need it.

🧩
Split a big taskEach method solves one small part (refinement, עידון)
♻️
ReuseWrite once, call many times
🔍
Read & testSmall pieces are easier to understand and check
public class Circles {
    public static void main(String[] args) {
        double a = circleArea(2.5);              // call: 2.5 goes into radius, the result comes back
        System.out.println("Area: " + a);
        printLine();                             // call a method that returns nothing
        System.out.println(circleArea(1) * 2);   // the returned value can be used inside an expression
    }

    // Returns the area of a circle with the given radius.
    private static double circleArea(double radius) {
        return Math.PI * radius * radius;
    }

    // Prints a separator line. Returns nothing (void).
    private static void printLine() {
        System.out.println("--------------------");
    }
}

Anatomy of a method

PartIn the exampleMeaning
Openingprivate staticA fixed opening for now. You'll learn what it means later.
Return typedoubleThe type of the value the method gives back. void = gives nothing back.
NamecircleAreaA verb or a description of what it returns, in camelCase
Parameters(double radius)The values the method needs, each with a type. Can be empty: ()
Body{ ... }The commands that run on each call
returnreturn Math.PI * ...;Ends the method and sends the value back to where it was called

The signature (חתימה) is the first line: return type, name, and parameters. It tells you how to call the method without reading its body.

What happens during a call

  1. Java calculates the value in the parentheses: circleArea(r * 2) with r = 1.5 → 3.0.
  2. The value is copied into the parameter: radius = 3.0.
  3. The body runs until return.
  4. The returned value replaces the call in the expression: double a = 28.27…;
Call by value (העברה לפי ערך)A parameter is a copy of the value you pass. If the method changes its parameter, the caller's variable stays the same. Try it in the trace simulator (program "Method call").
Types must matchA double parameter accepts any expression whose value is a number: circleArea(5), circleArea(x + 1), circleArea(Math.sqrt(2)). But an int parameter won't accept 2.5. Also, a non-void method must always reach a return.

Refinement: splitting a task into methods

Task: "Read the number of guests. Each eats 3 slices, a pizza has 8 slices and costs ₪45. Print how many pizzas to order and the total cost."

// main tells the story; each helper does one small job
int guests = in.nextInt();
int pizzas = pizzasNeeded(guests * 3);
System.out.println("Order " + pizzas + " pizzas, cost: " + cost(pizzas));

private static int pizzasNeeded(int slices) { return (slices + 7) / 8; }   // round UP without if
private static int cost(int pizzas)        { return pizzas * 45; }

9Trace Tables (טבלת מעקב)

A trace table lets you run a program by hand, line by line, to see what it does and find bugs. It has one column per variable and one for the output. Every row is one step.

  1. Make a column for the line number, one per variable, and one for the output.
  2. Go through the code in the order it runs. For each line that changes something, add a row.
  3. Write each new value. Leave a cell empty if the variable doesn't exist yet.
Exams love trace tablesIn the Bagrut, many questions are "what does this code print?". The trace table is how you answer them without mistakes.
